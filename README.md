# 股票学习工作台

面向 DSH Web 的模块化股票学习工作台。它使用独立的 `sidebar.panellist` + `main` 扩展点，不依赖 `dsh-worktable`，也不占用 `sidebar.footer.action`。

0.7.2 起，点击 DSH 侧栏的“股票学习”后，工作台会覆盖整个 DSH 页面，避免宿主侧栏压缩股票页面。工作台右上角提供“关闭”按钮；点击后通过 DSH 官方布局 API 返回正常对话页面。全屏工作台内部仍提供“股票学习应用”折叠组，应用栏可收窄为图标模式，状态保存在浏览器本地。

提供四个相互衔接的本地学习模块：

- 知识测试：综合、专项、章节和错题测试，自动评分、逐题解析、知识覆盖与本地答疑
- 情绪分析：记录涨跌停、最高连板和周期阶段，生成对应的学习提示
- 选股研究：用大盘、题材、趋势、量价和风险清单管理候选研究池
- 股市复盘：先在“今日交易数据”查看指数分时、成交额、涨跌分布、涨停梯队、热门题材和昨日涨停表现，再按“大盘 → 板块 → 个股 → 纠错”生成可编辑复盘草稿；检查修改后点击保存才进入历史记录

## 今日交易数据与一键复盘

交易复盘页面首先展示“今日交易数据 / 今日复盘 / 历史记录”三级页签；“一键生成今日市场复盘草稿”只属于“今日复盘”页签，不会再占据交易数据或历史记录页面顶部。

0.7.2 在“今日复盘”之前提供“今日交易数据”页签，参考量化复盘公开页面的功能结构，但不调用其私有加密接口，也不绕过登录或订阅权限。页面通过本项目服务端聚合公开行情，展示四大指数、上证分时、两市成交额及昨日对比、九档涨跌分布、涨跌停与封板率、涨停梯队、热门题材、晋级率和昨日涨停表现。每天首次成功采集后会按交易日自动保存到浏览器本地；两分钟自动刷新或点击“刷新并保存”会覆盖更新当天快照，不重复新增。日期输入和“已保存 N 天”下拉框可以直接读取本地历史快照，最多保留最近 90 个交易日。若某次刷新只有部分数据源失败（例如全市场涨跌分布暂时不可达），同交易日上一次成功保存的分区会被保留并标记为沿用快照，不再被 `null` 覆盖。严重异动预测及付费进阶指标不会采集。

复盘页通过 DSH 认证保护的同源接口 `/api/stock-quiz.recap` 在服务端获取腾讯指数，以及东方财富涨停、炸板、跌停、昨日涨停和行业数据。全市场涨跌分布优先使用东方财富，连接失败时自动切换新浪财经分页二分适配器。各数据分区独立标记成功、备用源或不可用；第三方失败不会被显示为真实的 0。

0.7.2 的知识规则报告不再只有单一“市场阶段”，而是按项目当前 56 个知识点拆成四条轴：大盘环境、穷变通久位置、情绪五阶段、预期现实四象限。报告同时展示赚钱效应评分、主线高度/宽度/深度候选、角色梯队、过度一致与退潮红灯、知识依据、仓位上限以及超预期/符合预期/低于预期三套次日剧本。单日数据无法确认的中军、真龙、补涨与穿越角色必须由用户人工确认。

页面采用紧凑操作区、全宽决策摘要、可折叠完整报告、四步编辑导航和固定保存操作条；桌面端将步骤、编辑区和辅助信息分层，窄屏自动切换为横向步骤导航与单栏表单。历史复盘采用按日期连续排列的单页报告流，每条记录直接展示结论、市场状态、主线、执行和纠错，完整知识证据按需展开，并支持分批加载。交易数据快照会自动保存，但自动生成的复盘报告只会填充可编辑草稿，不会立即写入复盘历史；两者是独立流程。用户需确认或修改市场四轴、主线五步、角色梯队、逐笔持仓体检、开仓三问、防腰斩检查、执行与纠错内容，并点击“保存复盘并进入历史”后才会持久化。同一交易日的自动复盘使用稳定 ID 更新，不会重复创建，也不会覆盖当日手工交易记录。测试进度、情绪记录、候选研究和最多 200 条复盘日志仍保存在浏览器本地。插件不连接券商账户，也不会自动发起交易。

页面保留手工填写和 JSON 快照导入作为第三方数据不可用时的可选兜底。快照接受扁平对象或 `{ "market": { ... } }` 形式，英文键和常用中文键均可，例如：

```json
{
  "date": "2026-10-09",
  "source": "a-stock-data",
  "indexChange": 0.65,
  "amount": 12860,
  "upCount": 3560,
  "downCount": 1480,
  "upLimit": 58,
  "downLimit": 6,
  "maxBoard": 7,
  "promotionRate": 42.5,
  "brokenRate": 21.4,
  "mainline": "机器人",
  "sectorFlow": "机械设备主力净流入居前"
}
```

测试内容依据本机「股票知识」知识库中的《周期论交易员手册》和《野人哥交易实战笔记》整理。所有内容仅用于学习与复盘，不构成投资建议。
