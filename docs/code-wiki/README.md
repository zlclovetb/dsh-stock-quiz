## 一句话概括

`dsh-stock-quiz` 是一个「股票学习工作台」DSH 插件，提供四个本地学习模块——**知识测试、情绪分析、选股研究、股市复盘**——并通过对 DSH 扩展点注册一个全屏覆盖式工作台，配合一个同源服务端接口 `/api/stock-quiz.recap` 聚合公开行情数据。
