### 依赖矩阵（谁引用谁）

| 模块 | 被谁引用 | 引用了谁 |
| --- | --- | --- |
| `catalog.js` | `questions.js`、`client.js`、`test` | 无 |
| `extra-questions.js` | `questions.js` | 无 |
| `questions.js` | `client.js`、`test` | `catalog.js`、`extra-questions.js` |
| `research.js` | `research-components.js`、`client.js`、`test` | 无 |
| `research-components.js` | `client.js` | `react`、`research.js` |
| `client.js` | 浏览器运行时（bundle） | `react`、`react-dom`、`questions.js`、`research.js`、`research-components.js` |
| `market-review.js` | `index.js`、`test` | 无（仅标准 API） |
| `index.js` | 宿主运行时 | `market-review.js` |
| `build.mjs` | `npm run build` | `node:fs/promises`、`node:path`、`node:url` |
| `quiz.test.mjs` | `npm test` | `node:assert/strict`、`node:fs`、`lib/*` |

关键观察：

- **宿主链路与客户端链路完全解耦**：`market-review.js` / `index.js` 不被客户端引用，`research-components.js` / `client.js` 不被宿主引用。
- **`research.js` 是唯一被两端"共享语义"的纯逻辑模块**：客户端用其归一化与合并逻辑，测试直接 `import lib/research.js` 做单测。
- **`catalog.js` 是知识点单一数据源**：`questions.js` 依赖它派生题库与卡片。

## 2. 外部依赖

### 运行时（peerDependencies，由宿主提供，不打包进本包）

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| `@deepseek-ai/cordis` | `>=4.0.0` | DSH 插件框架：`ctx.inject`、`ctx.slots`、`ctx.layout`、`connection.fetch.register` |
| `react` | `^18.2.0` | 客户端组件（`useState`/`useEffect`） |

### DSH 客户端注入依赖（`package.json` → `dsh.client.inject`）

| 依赖 | 用途 |
| --- | --- |
| `@deepseek-ai/dsh-client-ui-slots` | 扩展点（槽位）注册：`main`、`sidebar.panellist` |
| `@deepseek-ai/dsh-client-ui-layout` | 布局切换：`ctx.layout.selectPanel(null)` 关闭全屏 |

### 直接使用的浏览器/宿主标准能力（无第三方包）

- `fetch`、`AbortSignal.timeout`、`URL`、`URLSearchParams`、`Response.json`、`TextDecoder`（`market-review.js`）。
- `localStorage`、`document`、`window.__ModuleLoader__`、`crypto.randomUUID`、`confirm`、`setInterval`（客户端）。
- React 依赖 `react` / `react-dom` 由 bundle 的 `require` 注入（构建脚本把 `import React` 改写成 `require('react')`）。

### 无 devDependencies

`package.json` 中没有 `devDependencies` / `dependencies`；测试仅用 Node 内置模块。这意味着**安装本包不会引入额外依赖树**，宿主需自行满足 `cordis` 与 `react`。

## 3. 第三方数据源依赖（运行时网络）

服务端在请求时依赖以下**公开**行情接口（无私有加密接口）：

| 数据源 | 端点/域名 | 用途 | 备注 |
| --- | --- | --- | --- |
| 腾讯财经 | `https://qt.gtimg.cn/q=...` | 四大指数实时行情 | gbk 编码 |
| 东方财富 | `https://push2ex.eastmoney.com/...` | 涨停/炸板/跌停/昨日涨停池 | 需 `ut` token 常量 |
| 东方财富 | `https://push2.eastmoney.com/api/qt/clist/get` | 全市场涨跌分布（主）、行业排名 | 涨跌分布用排序分页 + 二分 |
| 东方财富 | `https://push2his.eastmoney.com/...` | 指数日线（kline）、上证分时（trends2） | 历史日期来源 |
| 新浪财经 | `https://vip.stock.finance.sina.com.cn/...` | 涨跌分布（备用源） | 东财失败时降级 |

设计原则：**分区独立 + 降级**。每个数据源由 `partition()` 包裹，单个源挂掉只会让该分区 `unavailable`，并把 `status` 降为 `partial`，绝不用 0 冒充真实数据。

## 4. 依赖版本与兼容性

- Node `>=20`：使用了 `AbortSignal.timeout`、`Response.json`、`crypto.randomUUID`、`URLSearchParams.size` 等较新能力。
- 客户端加载环境需支持 `window.__ModuleLoader__.load`（DSH Web 客户端提供的模块加载器）。
- 浏览器需支持 `createPortal`（react-dom）、`localStorage`。
