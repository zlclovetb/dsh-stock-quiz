# 01 · 项目概览

## 1. 项目定位

`dsh-stock-quiz` 是一款面向 **DSH Web** 的模块化「股票学习工作台」插件。它基于 DSH（DeepSeek Host）的 `cordis` 插件体系，同时向宿主提供：

1. **宿主侧（Host / Node）能力**：注册一个受 DSH 认证保护的同源服务端接口，用于聚合第三方公开行情数据。
2. **客户端侧（Web / React）能力**：注册一个覆盖整个 DSH 页面的大屏工作台，内含四个本地学习模块。

设计上明确「独立」：使用独立的 `sidebar.panellist` + `main` 扩展点，**不依赖 `dsh-worktable`，也不占用 `sidebar.footer.action`**。

> 所有内容仅用于学习与复盘，不构成投资建议；插件不连接券商账户，也不会自动发起交易。

## 2. 核心功能模块

| 模块 | 客户端视图 id | 说明 |
| --- | --- | --- |
| 知识测试 | `quizHub` / `quiz` / `result` / `coverage` / `qa` | 综合、专项、章节、错题测试；自动评分、逐题解析、知识覆盖与本地答疑 |
| 情绪分析 | `sentiment` | 记录涨跌停、最高连板与周期阶段，生成学习提示 |
| 选股研究 | `screener` | 用大盘、题材、趋势、量价、风险五维清单管理候选研究池 |
| 股市复盘 | `review` | 今日交易数据 →（按「大盘 → 板块 → 个股 → 纠错」）生成可编辑复盘草稿 → 保存进历史 |

## 3. 技术栈

| 层面 | 选型 |
| --- | --- |
| 运行时 | Node.js `>=20`（`package.json` `engines`） |
| 模块格式 | ESM（`"type": "module"`） |
| 插件框架 | `@deepseek-ai/cordis` `>=4.0.0`（peerDependency） |
| 客户端 UI | `react` `^18.2.0`（peerDependency）+ `react-dom`（`createPortal`） |
| 客户端构建 | 自研脚本 [build.mjs](file:///c:/Users/spring/Documents/stock_study/dsh-stock-quiz/scripts/build.mjs)，产出 `window.__ModuleLoader__` 单文件 bundle |
| 测试 | Node 内置 `node:assert/strict`（`node test/quiz.test.mjs`），无第三方测试框架 |
| 数据源 | 腾讯财经（指数实时）、东方财富（涨停/炸板/跌停/昨日涨停/行业/日线/分时）、新浪财经（涨跌分布备用） |

## 5. 包入口与 manifest

来自 [package.json](file:///c:/Users/spring/Documents/stock_study/dsh-stock-quiz/package.json)：

```jsonc
{
  "name": "dsh-stock-quiz",
  "version": "0.7.2",
  "type": "module",
  "main": "./lib/index.js",
  "exports": {
    ".": "./lib/index.js",          // 宿主模块
    "./client": "./lib/client.js",  // 浏览器 bundle
    "./package.json": "./package.json"
  },
  "files": ["lib", "cordis.patch.yml", "README.md"],
  "dsh": {
    "bundle": { "patch": "./cordis.patch.yml" },
    "client": {
      "platform": "web",
      "immediately": true,
      "inject": [
        "@deepseek-ai/dsh-client-ui-slots",
        "@deepseek-ai/dsh-client-ui-layout"
      ]
    }
  },
  "peerDependencies": {
    "@deepseek-ai/cordis": ">=4.0.0",
    "react": "^18.2.0"
  },
  "engines": { "node": ">=20" }
}
```

关键点：

- `exports["."]` 指向宿主入口，`exports["./client"]` 指向浏览器 bundle —— 这正是「双端」的来源。
- `dsh.client.inject` 声明客户端运行时依赖 `ui-slots`（扩展点注册）与 `ui-layout`（`layout.selectPanel` 全屏切换）。
- `dsh.bundle.patch` 指向 [cordis.patch.yml](file:///c:/Users/spring/Documents/stock_study/dsh-stock-quiz/cordis.patch.yml)，内容为：

```yaml
- insert:
    - id: stock-quiz
      name: dsh-stock-quiz
```

它把本插件以 `id: stock-quiz`、包名 `dsh-stock-quiz` 的形式插入 DSH 的 bundle 清单。

## 6. 版本演进线索（读代码可验证）

- `0.7.2`：交易复盘页拆成「今日交易数据 / 今日复盘 / 历史记录」三级页签；点击后全屏覆盖 DSH 页面并支持关闭返回。

- `schemaVersion: 3` 的交易数据快照结构、`ruleVersion: 'market-review-rules.v2'`、`knowledgeVersion: 'catalog-56.v1'` 等版本标识可用于判断数据结构兼容性。
